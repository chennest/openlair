## 修复登录按钮隐形（auth 页 CTA 按钮）

- 现象：`/login` 页登录按钮在 DOM 中存在但视觉上是一块白色空白（透明背景 + 白字）。
- 根因：`auth/index.vue` 用 `bg-[var(--grad-cta)]`，而 `--grad-cta` 是 `linear-gradient(...)`（image 非 color）。Tailwind 任意值默认编译成 `background-color: var(...)`，计算值阶段非法 → invalid at computed-value time → 回退为透明。
- 修复（方案 A）：按钮改挂 `cta-btn` class，在 `<style scoped>` 中用原生 `background: var(--grad-cta)` 简写（同 brand-mark 模式）；hover 同理。
- 附加坑：
  1. scoped 注释里写字面量 `bg-[var()]` 会被 Tailwind 当候选 class 扫描，产生 `background-color: var()` 非法 CSS 警告——注释里不要出现 Tailwind 类名字面量。
  2. `--primary-foreground: #ffffff`（src/assets/tailwind.css），透明背景时白字彻底不可见。
  3. 沙箱批量删除保护：`vite build` 清空 dist（>50 文件）会被 SAFE_DELETE_BULK_CONFIRM_REQUIRED 拦截；用 `pnpm run build -- --emptyOutDir false` 增量构建绕过。
- 验证：`pnpm run build`（vue-tsc 类型检查 + vite build）通过；dist/assets/auth-*.css 中确认 `.cta-btn{background:var(--grad-cta)}`。
