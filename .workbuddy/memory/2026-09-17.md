## 给超哥讲透「跟打选错 → 掌握门槛 3 翻到 5」

他说不理解这句话，并要求「所有业务的情况」。为此把后端掌握判定完整读了一遍（`backend/app/services/vocab.py`），讲清了下述口径（回话里已给全表）：

- 掌握不看 FSRS stability，只看 `correct_streak >= required_streak`；达标自动 `status='mastered'`，此后不再排课。
- `passed = correct && wrongTimes == 0` —— **一次作答里只要有任何一个错（打错字母 / 选错释义 / 点不认识 / 跳过），整次就不算答对**。
- `required_streak` 只在「首次识词判断」（`required_streak <= 0` 的那一次作答）定终身：passed → 3（眼熟），不 passed → 5（不熟悉）；同时 `identify_result` 记 know/unsure。
- 「跟打选错」= 释义四选一选错了 → wrongTimes≥1 → 不 passed → **新词第一次就被判成"不熟悉"，门槛 5 而不是 3**。以前跟打释义是白送的（不算题），只有手滑打错字母才会判错，所以从没暴露这个问题。
- 未掌握期间 due 一律压到「本地次日零点」（`UNMASTERED_MAX_INTERVAL=1 天`），达标后才交回 FSRS 曲线 —— 否则 2→11→45 天的间隔会让「再连对两次」变成两个月。
- 手动路径：标已掌握直接改 status（不写 first_learned_at）；「取消记住」清零 correct_streak 但**保留原 required_streak**；收藏/取消收藏只动 collected；移出错词本 = `wrong_active=false`。**答对一次即自动移出错词本**（`wrong_active = not passed`）。
- 错词本 / 收藏复习 source 不受每日目标限制（`start_session` 里 remaining_* 只对 `source=='book'` 计算）。
