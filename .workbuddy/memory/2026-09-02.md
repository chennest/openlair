## gpt-image-2-skill Rust CLI 更新（0.3.6 → 0.7.3）

- 背景：skill 目录 `D:\001-code\笔记\.agents\skills\gpt-image-2-skill` 的 wrapper 脚本钉死 `VERSION = "0.3.6"`，缓存二进制过旧（npm 裸 CLI 已是 0.7.3）。
- 处理：从上游 `Wangnov/gpt-image-2-skill` main 分支同步全部 skill 文件（SKILL.md / scripts / references / agents），wrapper 随之钉到 0.7.3；手动下载 release zip 并放置到 `~/.cache/gpt-image-2-skill/0.7.3/x86_64-pc-windows-msvc/gpt-image-2-skill.exe`（SHA256 校验通过）。doctor + selftest 全绿，provider 走 lcc-newapi（openai-compatible）。
- **关键坑 1**：wrapper 在 Windows 用 `tar -xf` 从 stdin 解 zip，需要 bsdtar；Git Bash 的 `/usr/bin/tar`（GNU tar）排在 PATH 前面会抢先导致 "does not look like a tar archive"。
- **关键坑 2**：**bsdtar 从 stdin 流式解 zip 会静默丢掉部分条目（exe 消失）且退出码为 0**——上游 wrapper 的 Windows bootstrap bug（tar.xz 不受影响）。规避：手动从文件解压 exe 放进缓存路径，wrapper 的 cache 解析直接命中。
