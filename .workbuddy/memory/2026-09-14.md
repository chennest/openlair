## 词书详情页（点词书看单词状态）落地

**需求来源**：超哥要"点词书能进去看有哪些词、每个词有没有被用/被听"，并明确要求**先问需求再施工**。
流程：AskUserQuestion 敲定 4 项 → 出 inline 版式线框对齐 → 施工。

**确认的方案**
- 形态：独立详情页 `/vocab/book/:id`（非抽屉/弹窗）
- 行内状态：学习状态 + 对错次数 + 复习时间 + 收藏/错词标记 + **模式覆盖**（跟打/听写/自测/默写各练过几次）
- 筛选/搜索/排序/滚动加载全要；行内快操（收藏、标记掌握、移出错词本）+ 点行展开释义例句短语

**后端**（backend/app/）
- `repositories/vocab.py`：新增 `book_summary_counts`、`_book_words_query`（查询骨架，分页与计数共用）+ `list_book_words_page`（status/keyword/sort）、`list_progress_by_word_ids`、`practice_mode_stats`（按 (word_id, mode) 聚合 `vocab_practice_logs`）
- `services/vocab.py`：`list_book_words` 扩展参数并拼 `progress` + `practice`；新增 `book_summary`；新增常量 `STATUS_FILTERS`/`WORD_SORTS` 与 `_practice_dto`
- `api/v1/endpoints/vocab.py`：`/books/{id}/words` 加 status/keyword/sort；新增 `GET /books/{id}/summary`
- `docs/backend-architecture.md` 接口表与说明同步

**契约决策（重要）**
- `progress` 按 (user, word) 全局唯一、跨词书共享 → 详情页展示的是"该词的全局状态"，不是"本书内单独的进度"
- 模式覆盖口径取**全局**：错词本/收藏练习的 `session.book_id` 记为 0，按词书过滤会漏
- `sort=recent` 把从未练过的沉底：先按 `last_review IS NULL` 排（SQLite 无 NULLS LAST）
