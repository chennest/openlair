# 2026-09-22 工作日志

## 新增：顶栏日期「上班 / 休息 / 节日」徽标（节假日 + 调休补班识别）

### 需求
超哥要求日期显示时能看出当天是上班日还是休息日。

### 调研结论（开源方案对比）
| 方案 | 代表 | 数据形态 | 判定 |
|---|---|---|---|
| 稀疏配置表（选中） | JayceChant/goliday | 每年 TOML，只写被调整日期（20~40 条） | 配置优先 → 未覆盖回退周末 |
| 全量快照 | NateScarlet/holiday-cn | `{year, papers, days[{name,date,isOffDay}]}` | 查表，但 isOffDay 布尔值把「法定节日」与「调休放假」混在一起 |
| 在线 API | timor.tech | type 枚举 0/1/2/3 | 个人公益服务，官方明确不建议用于生产核心链路 |

关键发现：holiday-cn 的 `isOffDay` 表达力不足（10/5 调休放假与 10/1 法定节日同为 true），
故采用「两手稀疏表」模型区分 `festivals` / `workdays`，而非沿用单一布尔值。

### 落地实现（纯前端，**后端零改动，无数据库表**）
- `lairweb/src/lib/holidays/types.ts`：`YearConfig` / `DayInfo` / `DayKind` 类型
- `lairweb/src/lib/holidays/2026.ts`：稀疏表，33 天放假 + 6 天调休补班 = 39 条
- `lairweb/src/lib/holidays/index.ts`：判定核心
  - `dayInfo()` 优先级：festivals → workdays → 周末 → 工作日
  - `dayBadge()` 三档徽标；`daysToNextRest()` 距下个休息日
  - **跨年**：按日期自身年份取配置（不沿用展示月份）
  - **年份缺失**：`degraded: true` 标记 + 一次性 console.warn，不静默当周末
  - **地区**：注释明确只覆盖中国大陆，港/澳/台需各自维护
- `lairweb/src/App.vue`：桌面顶栏 + 手机顶栏两处接入徽标
- `lairweb/src/style.css`：`.day-badge` 四档样式（holiday 暖橙 / rest 绿 / work 蓝 / makeup 橙描边）
- `scripts/gen-holidays.mjs`：**年更脚本**，从 holiday-cn 或本地 JSON 生成 `{year}.ts`，带校验

### 验证
- 数据表与 holiday-cn 官方 39 条**逐条交叉核对完全一致**；补班日均为周末 ✓
- vite-node 跑 15 项断言全过（含降级路径、跨年、中秋撞周末等边界）
- `pnpm run build` 类型检查 + 打包通过

### 年更流程（每年 11 月国办发文后）
```bash
node scripts/gen-holidays.mjs --year 2027 --remote
```
然后两处都要改：① 在 index.ts 的 REGISTRY 登记新年份 + 补 import；② 抽查春节/国庆调休首尾日。
